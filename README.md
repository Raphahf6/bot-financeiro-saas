# Bot Financeiro SaaS

Bot financeiro com backend Node.js para automacao, comandos e apoio a gestao financeira via integrações conversacionais.

## O que este projeto mostra

- Backend Express.
- Bot com Telegraf.
- Integracao com Supabase.
- Uso de IA com Google Generative AI.
- Rotinas agendadas com node-cron.

## Stack

- Node.js
- Express
- Telegraf
- Supabase
- Google Generative AI
- node-cron
- dotenv

## Como rodar

```bash
npm install
node index.js
```

Configure as variaveis de ambiente antes de executar.

## Observacao

Projeto de laboratorio para automacao financeira e assistentes conversacionais. Nao exponha tokens de bot, chaves de IA ou credenciais do banco no repositorio.
